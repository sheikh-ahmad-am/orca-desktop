ORCA — SQL practice (desktop, fully offline)

HOW TO RUN
1. Extract this whole ZIP to any folder (keep Orca.exe, orca-desktop.jar
   and the jre folder together — do not move Orca.exe out on its own).
2. Double-click Orca.exe. No installation, no internet needed.

YOUR DATA
Progress, generated datasets and imported CSV tables are stored per-user at
  %LOCALAPPDATA%\Orca
(XP, solved problems, streak and mistakes survive restarts. Delete that
folder to start completely fresh.)

WHAT'S INSIDE
- Orca.exe          tiny native launcher (starts the bundled runtime)
- orca-desktop.jar  the app itself (same problems, datasets and rules as the phone app)
- jre\              bundled Java 17 runtime (Temurin) — nothing to install

Windows may show a SmartScreen note for an unsigned app on first run:
choose "More info" -> "Run anyway".
